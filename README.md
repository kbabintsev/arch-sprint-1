# Задание 1 (проект Mesto)
## Вводная
Допустим, мы провели предварительный анализ проекта и приняли решение о его разбивке на микрофронтенды ввиду его сложности и масшатбности в будущем, у нас есть команды опытных фронтенд разработчиков на React.  

##  Бизнес-функции приложения
Сгруппируем бизнес-функции приложения, которыми будут заниматься команды разработки микрофронтендов:
* регистрация и аутентификация (формы регистрации, аутентификации)
* профиль пользователя (редактирование, аватар)
* места (добавление, удаление, лайки)

## Выбор инструмента для создания микрофронтендов
Для микрофронтендов выбрал инструмент Webpack Module Federation.  
Проект сейчас реализован на React, использование других фреймворков скорее не целесообразно (у нас команды React разработчиков) и стоит сохранить его относительную легковестность для публичного интернет проекта. В этом случае, Webpack Module Federation функция shared dependencies будет дополнительным плюсом.  
Инструмент Webpack Module Federation хорошо интегрируется в React-проекты, сообществом накоплен большой опыт его внедрения.

## Межмодульное взаимодействие
Для взаимодействия между микрофронтендами выбрал библиотеку глобального состояния Redux.  
В текущем проекте уже присутствует глобальное состояние - это данные аутентификации и профиль пользователя (CurrentUserContext).  
Redux - одна из наиболее популярных библиотек, есть имплементация для React и управление сложным состоянием пригодится для иерархической информации о пользователе.

## Структура
Для удобства разработки, микрофронтендную имплементацию положил рядом с исходной в директорию `microfrontend`.  
Верхний уровень каталогов:
* host - хост приложение, отвечает за каркас приложения и подключает другие микрофронтенды.
* components - "микрофронтенд" предоставляет общие компоненты другим микрофронтендам: такой, как PopupWithForm или InfoTooltip (сейчас используется сейчас только в auth, поэтому оставил там).
* auth - микрофронтенд отвечает за аутентификацию, регистрацию
* profile - микрофронтенд профиля пользователя
* places - микрофронтенд отвечает за места и все, что с ними связано: отображение, добавление, редактирование, лайки
Структура каждого микрофронтенда идентична исходному приложению для сохранения всех относительных путей (стилей, изображений и прочее)

## Уровень 3. Запуск готового кода
```bash
cd .\microfrontend\
npm i
npm run build
npm run start
```
